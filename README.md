## 📦 Repository Structure

```
sam-ai/
├── website/            # Sam AI website (HTML/CSS/JS + live chat demo)
│   ├── index.html
│   ├── style.css
│   └── script.js
├── docs/               # copy of website/ served by GitHub Pages
├── model/
│   └── model_card.md   # sam-1 model card (Hugging Face format)
├── sam_chat.py         # sam-1 CLI demo chatbot (pure Python, no deps)
└── .github/workflows/  # auto-deploy website to GitHub Pages
```

## 🚀 Run Locally

**Website** — just open `website/index.html` in a browser, or:

```bash
python3 -m http.server 8000   # then visit http://localhost:8000/website
```

**CLI chatbot demo:**

```bash
python3 sam_chat.py
```
